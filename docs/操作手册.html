🍰 像素蛋糕 · 操作手册

本地 AI 修图客户端（Windows 11）

版本 0.2.1 · 安装 / 部署 / 使用 / 卸载

一、安装

1.1 系统要求

项目要求
操作系统Windows 10 / Windows 11（64 位）
GPU（AI 功能）NVIDIA 显卡（推荐 RTX 30 系列及以上），驱动 ≥ 550 系列
运行库Microsoft VC++ 运行库（下载）
内存≥ 8 GB
磁盘≥ 2 GB 可用空间（模型 + 照片数据另计）

注意AI 推理需要支持 CUDA 的 NVIDIA 驱动；无独显时应用仍可启动，AI 功能将自动降级（仅基础调色 / 手动美型可用）。

1.2 安装步骤

  1. 获取安装包：从发布渠道下载 像素蛋糕-x.x.x-setup.exe（NSIS 安装包）。
  2. 运行安装包：双击安装程序，如遇 SmartScreen 提示选择「仍要运行」。
  3. 选择安装目录：默认安装到 %LOCALAPPDATA%\像素蛋糕，可修改。
  4. 完成安装：点击「完成」，桌面将出现「像素蛋糕」快捷方式。
  5. 确认运行库：若启动报缺失 DLL，先安装 VC++ 运行库。

1.3 首次启动

首次启动后应用会创建数据目录并初始化数据库：

路径用途
%APPDATA%\com.pixcake.desktop\pixcake.db项目 / 照片 / 编辑参数 / 设置（SQLite）
%APPDATA%\com.pixcake.desktop\libraries\客片组目录
%APPDATA%\com.pixcake.desktop\models\AI 模型文件（应用内下载）

提示数据完全本地保存，备份以上目录即可迁移。

二、部署（AI 模型）

AI 功能（美型 / 追色 / 磨皮）依赖 4 个 ONNX 模型，需在应用内一次性下载。模型合计约 480 MB（2026-08-30 实测：SCRFD 3.3 MB / 2DFAN4 97.9 MB / BiSeNet 93.6 MB / GPEN 284.3 MB）。

模型文件名用途
SCRFD 2.5Gscrfd_2.5g.onnx人脸检测
2DFAN42dfan4.onnx68 点关键点（美型）
BiSeNetbisenet_resnet_34.onnx皮肤分割（追色）
GPEN BFR 512gpen_bfr_512.onnx皮肤增强（磨皮）
  1. 打开应用，在右侧面板底部找到「模型下载」区域。
  2. 点击各模型旁的「下载」按钮，等待进度完成（来源 hf-mirror 镜像，国内可达）。
  3. 下载完成后对应项显示 已下载。
  4. 重启应用（或继续使用），AI 功能自动启用；未下载的模型对应功能自动降级。

3.2 基本流程

  1. 打开项目（推荐）：菜单「文件 → 打开项目…」，或左侧「打开照片文件夹…」，在系统目录对话框中选中存放照片的文件夹，应用自动建项目并导入全部 RAW / JPEG / PNG。
  2. 新建项目：左侧顶部输入客片组名称 → 点击「新建」。
  3. 导入照片：菜单「文件 → 导入照片…」用系统文件对话框多选照片（支持 .cr2 .arw .nef .dng .jpg .png 等）。
  4. 选择照片：在左侧照片列表点击要编辑的照片。
  5. 编辑：在右侧面板调整参数，编辑即自动预览（无需手动刷新）。仅调色与滤镜时走 WebGL2 实时预览——参数在 GPU 上即时渲染，拖动滑块零延迟；启用 AI 操作（磨皮 / 美型 / 祛瑕 / 追色）后自动切回后端全链路预览。
  6. 导出：菜单「导出…」或右侧「导出（全分辨率）」，选择导出目录后输出 16bit TIFF 成品。

3.3 功能速查

🧱 中性灰磨皮

  • 启用后拖动 平整 ka（皮肤平滑）与 立体 kb（保留光影）。
  • 模式：平整+立体（推荐）/仅平整/仅立体。
  • 已下载 GPEN 模型时，ka 强度会走 GPEN 皮肤增强。

🎯 AI 美型

  • 启用后拖动 瘦脸（0–100）调整液化强度。
  • 需已下载 SCRFD + 2DFAN4 模型；未下载时自动回退为 5 点大眼。
  • 瘦身 / 天鹅颈 / 面部丰盈为规划功能，暂未启用。

🎨 AI 追色

  • 启用后点击「选择…」按钮，用系统对话框挑选参考样片（或手动输入路径）。
  • 选择模式：和谐（保守）/ 极致（强烈）。
  • 引擎会分割皮肤区域，把样片肤色迁移到照片，不动背景 / 唇色。

🩹 祛瑕

  • 选择类型（祛痣 / 纹身 / 背景 / 牙齿）→ 点击「绘制祛瑕区域」。
  • 在画布上点击逐个添加多边形顶点，≥3 点后「完成区域」。
  • 区域出现在列表，可删除重画。

🎛️ 基础调色 · 🌈 滤镜 · 导出

  • 调色：曝光 / 对比度 / 色温 / 色调 / 饱和度 / 颗粒 / 暗角。
  • 滤镜：选择预设（暖色 / 冷色 / 黑白 / 鲜艳）+ 强度（0–100%），强度作用于最终导出。
  • 实时预览：调色与滤镜参数在画布上以 WebGL2 GPU 渲染即时反馈；选用底图自动加载，无需等待后端重算。
  • 导出：菜单「导出…」或右侧「导出（全分辨率）」，在系统对话框中选择导出目录；「批量导出…」把当前项目全部照片按统一风格导出。
  • 导出格式可在设置中选择：16bit TIFF（默认，无损）或 8bit PNG（通用）。
  • 导出完成后可点击右侧 📂 按钮，在资源管理器中定位成品文件。

3.4 设置面板

菜单「视图 → 设置…」打开设置面板，设置即时生效并自动保存：

设置项选项说明
界面主题深色 / 浅色切换整套界面配色
预览尺寸小 / 中 / 大 / 超大预览代理图最长边（800–2400px），越大越清晰、越耗性能
导出格式16bit TIFF / 8bit PNG导出的默认文件格式
默认导出目录浏览…留空则导出到源照片旁
默认导入目录浏览…打开项目 / 导入 / 选参考图对话框的起始目录

提示设置保存在 pixcake.db 的 setting 表中，重开应用后仍然生效。

四、卸载

4.1 标准卸载

  1. 打开 Windows 设置 → 应用 → 已安装的应用，找到「像素蛋糕」。
  2. 点击「卸载」，确认后运行卸载程序，删除程序文件与快捷方式。
  3. 也可在开始菜单右键「像素蛋糕」→「卸载」。

4.2 清理数据（可选）

卸载程序不会删除你的数据（照片 / 编辑参数 / 模型 / 设置）。如需彻底清理：

  1. 在文件资源管理器地址栏输入 %APPDATA%\com.pixcake.desktop 回车。
  2. 删除该目录（内含 pixcake.db、libraries、models）。
  3. 删除桌面快捷方式（如卸载后残留）。

注意此操作不可恢复，请先备份需要的照片数据。
